Aula 08 - Router Handlers (Métodos GET e POST)

Projeto prático desenvolvido com NestJS para exemplificar o funcionamento de Router Handlers, lidando com rotas de listagem (GET) e criação (POST) utilizando DTOs.

 Funcionalidades

- **GET convidados: Retorna a lista completa de convidados.
- **POST convidados: Recebe os dados de um novo convidado via CriarConvidadoDto e confirma a adição.

 Tecnologias Utilizadas

- NestJS
- TypeScript
- Node.js
