Codificação para Back-End

Este repositório contém os projetos, exercícios e aplicações desenvolvidas durante a unidade curricular de Codificação para Back-End.

 Objetivos do Curso
- Compreender os fundamentos do desenvolvimento server-side.
- Construir APIs RESTful estruturadas e escaláveis.
- Aplicar boas práticas de arquitetura de software utilizando frameworks modernos.

 Tecnologias e Ferramentas
- **Node.js** (Ambiente de execução JavaScript)
- **NestJS** (Framework para construção de aplicações server-side eficientes e escaláveis)
- **TypeScript** (Superset JavaScript com tipagem estática)
- **Git e GitHub** (Controle de versão e hospedagem de código)
